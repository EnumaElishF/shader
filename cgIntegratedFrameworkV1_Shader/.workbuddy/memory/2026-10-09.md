# 2026-10-09

## 诊断：foo.effect 溶解参数在编辑器与运行时表现不一致

工程：Cocos Creator 3.8.7；素材：assets/effect/foo.effect、assets/material/foo.mtl、assets/scripts/noiseChange.ts、assets/texture/柯西.png、assets/texture/噪声图.png

### 根因（已定位并验证）
运行时 `uv0` 语义改变 —— 动态合图。
1. `柯西.png` 的 SpriteFrame `packable = true`（默认值），贴图采样参数 linear/linear/none，尺寸 126x126 → 满足合图条件。
2. 引擎 `cocos/2d/utils/dynamic-atlas/atlas-manager.ts`：
   - L169-171 `init(): this.enabled = !macro.CLEANUP_IMAGE_CACHE`；`macro.CLEANUP_IMAGE_CACHE` 默认 false（macro.ts:1124），仅 NATIVE/MINIGAME/RUNTIME_BASED 置 true（macro.ts:1131-1132）→ Web 预览默认开启合图。
   - L286-287 `packToDynamicAtlas(): if (EDITOR_NOT_IN_PREVIEW || !this._enabled) return;` → 编辑器不打包，预览/运行时才打包（编辑器与运行时的不对称来源）。
   - L192 `if (!spriteFrame.packable) return null;`
3. `sprite-frame.ts` L1141-1153 `_setDynamicAtlasFrame()` 把 `_texture` 换成图集贴图、`_rect` 换成图集子矩形并 `_calculateUV()` → `a_texCoord`(uv0) 变成图集空间子区间（约 0.x），不再是 [0,1]。
4. `foo.effect` L61 用同一个 `uv0` 采样自定义噪声图 `u_dissolveMap`，而引擎不会重映射用户贴图 → 噪声被读取到极小偏移区域，溶解花纹缩放/错位，与编辑器不同。`cc_spriteTexture` 不受影响（引擎同步换图+UV）。

### 次要因素
`noiseChange.ts` L14-18 每帧 `mat.setProperty('dissolveThreshold', this.dissolveThreshold)`，scene 中组件值 = 0，会覆盖 foo.mtl 里保存的 0.04。

### 修复方向
- 官方推荐：取消 `柯西.png` SpriteFrame 的 Packable；或 `spriteFrame.packable = false`（需在首次渲染前）；或全局 `DynamicAtlasManager.instance.enabled = false`。
- 脚本改为仅在值变化时 setProperty，或 start() 中先 `getProperty` 读回材质初值；需要多节点独立值时应 clone 材质。
